# UI Design Standards

AlistraGIS UI should be clear, operational and map-friendly. Dense workflows should prioritise scanning, filtering and quick action over decorative layout.

## Standards

- Keep field screens simple. See [[Field User Experience]].
- Make permission states visible. See [[Permissions Model]].
- Keep map controls predictable. See [[Main Map]].
