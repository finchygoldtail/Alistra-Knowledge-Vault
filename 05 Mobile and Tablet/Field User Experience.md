# Field User Experience

Field workflows should minimise taps, reduce noise and prioritise the current job, current map view and required upload.

## Priorities

- Job pack access through [[Work Packs]].
- Production upload through [[Production API]].
- Audit completion through [[Audits API]].
- Map navigation through [[Main Map]].
