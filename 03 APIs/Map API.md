# Map API

Supports map state, layers, measurements and navigation for [[Main Map]]. Drawing operations must respect [[Permissions Model]].

## Notes

- Managers and users may navigate, measure and toggle layers.
- Managers and users cannot draw.
- Admin and super-admin roles may draw where allowed.
