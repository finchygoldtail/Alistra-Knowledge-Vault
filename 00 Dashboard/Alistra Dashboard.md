## Platform Snapshot

AlistraGIS is an API-first fibre delivery platform with a React, TypeScript and Vite frontend, Leaflet and react-leaflet mapping, Firebase Authentication, Firestore and Storage, and Vercel deployment.

The product knowledge base lives in Obsidian. GitHub remains the source-code repository. Codex is used for implementation work, and [[FRIDAY Vision|FRIDAY]] will become the AI assistant and platform knowledge agent.
