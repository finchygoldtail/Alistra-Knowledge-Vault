# Vault Guide

## Where things belong

- `00 Dashboard` — navigation, current priorities and the inbox.
- `01–06` — product strategy, architecture, APIs, user interfaces and product features.
- `07–10` — implementation tasks, testing, security and infrastructure.
- `11–18` — business, legal, clients, intellectual property, standards, AI, media and commercial readiness.
- `19 Research and Development` — contemporaneous R&D evidence, journals, registers and claim support.
- `90 Templates` — reusable note starters.
- `99 Archive` — completed or superseded material kept for reference.

## Filing rules

1. Give each note one clear home based on its main purpose.
2. Link related notes with Obsidian wikilinks rather than duplicating the same content.
3. Put unfinished or uncertain material in [[Inbox]].
4. Prefer descriptive titles; add a date only for audits, reports, meetings and other time-specific records.
5. Archive stale notes instead of leaving them mixed with current operating material.

## Regular tidy-up

- Clear [[Inbox]].
- Update [[Current Sprint]], [[Active Bugs]] and [[Codex Backlog]].
- Confirm dashboards still point to current notes.
- Move completed reports and superseded plans to `99 Archive`.
- Check that new notes use a suitable file from `90 Templates`.
