# Business Model

## Model

AlistraGIS supports hosted subscriptions (the only model live today, on Firebase), client-hosted deployments (architecturally built via a Postgres/PostGIS backend, but deliberately not enabled for any customer yet), maintenance packages, upgrades, and possible API buyout options. The licence engine already meters seats, feature modules and plan tier (trial/subscription/enterprise) per company — see [[Pricing Models]] for how that maps to a real commercial structure.
